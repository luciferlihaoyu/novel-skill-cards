# 通用技能卡｜AI 自动写作版

## 使用说明

- 本文件是平台无关的提示词模板，不依赖特定模型、插件、文件结构或工具。
- 每张卡可单独复制到任意支持自定义指令的系统，也可由工作流按编号串联。
- 将 `{{变量}}` 替换为实际内容，或在系统中配置为输入字段。材料不足时保留“待确认”，不得补造前情。
- 本套卡负责自动写作的规划、约束、状态与质量控制；正文生成步骤可接入任意模型或现有写作模块。
- 统一使用三种资料状态：**正文事实**、**大纲计划**、**候选设定**。正文未发生的事件不得写成事实。

## A00｜自动写作总控卡

**适用场景**：需要让系统自动完成长篇小说的连续章节生产。

**总控指令**：

你负责调度小说自动写作流程，不直接代替正文生成模块。根据任务选择流程，并严格执行状态与质量门禁。

1. 新建作品：依次执行 A01、A02、A03、A04。
2. 续写已有作品：先依据实际提供资料执行 A02、A03、A08、A09，建立当前基线；资料不足时明确列出缺口。
3. 生成下一章：执行 A05、A07；P0 清零后执行 A06，再调用正文生成模块。
4. 正文完成后：依次执行 A10、A11、A12；需要返修时执行 A13，涉及现实事实或发布风险时执行 A14。
5. 每章归档：保存正文、摘要、任务完成情况、状态变更、伏笔变更、门禁结果、修订记录和下一章承接事项。
6. 单项任务只调用对应卡，不强迫用户执行全流程。

**质量门禁**：P0 为阻断问题，未清零不得生成正文或进入下一章；P1 为必须返修问题；P2 为可选优化。默认最多自动返修两轮，仍未通过则停止并请求人工判断。

## A01｜写作任务解析卡

**适用场景**：新任务、需求变化或约束不清时

**任务目标**：把模糊需求转为可执行、可验收的写作任务。

**输入材料**：用户要求、已有创意、目标平台、篇幅、文风参考、禁区。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 提取题材、主角、核心冲突、目标读者、预计篇幅和本次交付物。
2. 把要求分为硬性约束、风格偏好、可自由发挥项和禁止事项。
3. 检查要求之间的冲突，例如指定结局与人物底线不相容。
4. 只询问会改变核心方向的缺失信息；其余使用“候选设定”并明确标注。
5. 写出可验证的完成标准，不使用“精彩一点”等无法验收的表述。

**输出要求**：
写作任务书；硬性约束；风格偏好；禁止事项；待确认问题；完成标准。

**限制与判断边界**：不生成正文，不擅自改变题材、结局和核心人物关系。

## A02｜作品圣经管理卡

**适用场景**：建立、查询或变更设定时

**任务目标**：建立并维护全作品唯一、可追溯的设定来源。

**输入材料**：任务书、用户设定、已有大纲、正式正文及旧版设定。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 按世界规则、地理、势力、历史、职业、科技或能力体系分类。
2. 为每条设定记录来源，并标记正文事实、大纲计划或候选设定。
3. 检查规则、例外、成本与边界是否互相冲突。
4. 识别能持续制造选择、代价和冲突的设定，而非只堆积背景。
5. 核心变更时列出受影响章节；未经确认不得静默覆盖正文事实。

**输出要求**：
作品圣经；设定条目表；规则边界；未决设定；冲突与影响清单。

**限制与判断边界**：正文事实优先于旧大纲；资料不足时保留空白，不编造历史。

## A03｜人物模型与声纹卡

**适用场景**：建档、人物转变或对话失真时

**任务目标**：让人物的行为有动机，语言与选择具有稳定辨识度。

**输入材料**：人物小传、关系要求、相关正文、当前人物状态。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 记录外在目标、内在需求、恐惧、秘密、底线、能力边界及成长方向。
2. 建立关系现状、关系诉求和发生变化所需的触发条件。
3. 从正文提取词汇、句长、称呼、礼貌程度、回避习惯与知识范围。
4. 记录人物通常不会采取的行为，以及反常行为所需的铺垫。
5. 更新状态时引用正文证据，区分长期性格与临时处境。

**输出要求**：
人物档案；关系表；声纹卡；行为禁区；成长方向；当前状态与知情范围。

**限制与判断边界**：不把单一性格标签当作完整动机，不为剧情方便让人物无理由改变。

## A04｜长篇结构与分卷规划卡

**适用场景**：新书规划、分卷或主线失控时

**任务目标**：把核心创意扩展成能持续生产且不断升级的长篇结构。

**输入材料**：任务书、作品圣经、人物档案、预计篇幅与结局要求。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 确定核心矛盾、主角长期目标和终局方向。
2. 拆分阶段与分卷，为每卷设置外部目标、人物变化和阶段高潮。
3. 安排支线的进入、发展、并线或退出位置。
4. 规划长期伏笔与关键真相的释放层次。
5. 检查冲突是否只是换场景重复，能力与反派升级是否有代价和新选择。

**输出要求**：
故事总纲；分卷规划；主支线清单；阶段高潮；长期伏笔规划；连载风险。

**限制与判断边界**：每卷须有相对独立的目标并推进全书主线；不得只写“遇到更强敌人”。

## A05｜章节任务与场景规划卡

**适用场景**：每次生成正文前

**任务目标**：在正文生成前明确本章必须完成的剧情与状态变化。

**输入材料**：分卷纲、前章摘要、人物状态、伏笔表、目标字数和下一章约束。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 确定视角人物、即时目标、阻碍、结果和代价。
2. 按“进入状态—冲突变化—离开状态”拆分场景。
3. 列出必达事件、人物变化、信息释放和禁止提前泄露的内容。
4. 安排章末的新问题、决定、危机或局势变化。
5. 检查删除本章后是否影响后续；无影响时合并、重写或删除该章计划。

**输出要求**：
章节任务卡；场景顺序；必达事项；信息边界；章末钩子；字数分配。

**限制与判断边界**：计划没有有效状态变化时不得直接生成正文，先修正章节任务。

## A06｜上下文装配与记忆压缩卡

**适用场景**：正文生成前资料过多或跨章续写时

**任务目标**：为正文生成提供必要、相关且无版本冲突的上下文。

**输入材料**：章节任务卡、作品圣经、人物档案、近期正文、前情摘要和伏笔表。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 优先装入用户硬约束、本章任务和会阻断写作的设定。
2. 只加入本章涉及的人物状态、地点、物品、伏笔和关系。
3. 用近期正文保留语气与衔接，用摘要补充远期前情。
4. 删除重复摘要、无关背景和低优先级候选设定。
5. 发现版本冲突时保留来源并请求校验，不擅自选择有利版本。

**输出要求**：
本章上下文包；前情摘要；相关状态；相关设定；待呼应事项；禁止事项。

**限制与判断边界**：上下文不足时不得编造旧剧情；明确标记缺失资料并转入 A07。

## A07｜写前可行性校验卡

**适用场景**：章节计划完成后、正文生成前

**任务目标**：在消耗正文生成前阻断必然导致前后矛盾的章节计划。

**输入材料**：章节任务卡、正文事实、人物状态、时间线、空间位置和物品记录。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 核对人物是否具备行动所需能力、资源、信息和动机。
2. 核对日期、行程、伤病、身份、装备和关键物品是否连续。
3. 检查计划是否违反世界规则或前一章结果。
4. 检查是否提前泄露信息、跳过必要铺垫或重复已完成事件。
5. 将问题分为 P0、P1、P2；P0 未清零时返回 A05 修正计划。

**输出要求**：
通过／有条件通过／不通过；阻断问题；章节计划修订指令。

**限制与判断边界**：只有 P0 清零才能进入正文生成；不得用“正文里再解释”绕过硬冲突。

## A08｜伏笔与信息差管理卡

**适用场景**：埋设、回收伏笔或角色获知信息时

**任务目标**：管理伏笔生命周期和每个角色合理的信息边界。

**输入材料**：大纲、正式正文、章节摘要、人物知情记录和计划回收位置。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 记录伏笔的埋设、强化、误导、回收及对应证据。
2. 区分读者知道、视角人物知道和其他角色知道的信息。
3. 为角色新获知的信息记录来源、时间和可信程度。
4. 提醒长期未推进、重复埋设或临近计划回收点的伏笔。
5. 发现角色越界知情时标记 P0 或 P1，并追溯信息链断点。

**输出要求**：
伏笔台账；角色知情表；信息来源；回收提醒；信息越界警告。

**限制与判断边界**：伏笔未回收不必然是错误；必须结合计划回收位置判断。

## A09｜时间线、空间与物品追踪卡

**适用场景**：行程、伤病、能力、装备或物品变化时

**任务目标**：维护可客观核对的时间、位置、状态和物品连续性。

**输入材料**：正文、章节摘要、人物行程、状态记录和物品清单。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 提取日期、时段、地点、行程和行动耗时。
2. 更新人物位置、伤病、能力、身份、资源和装备。
3. 记录关键物品的来源、持有者、消耗、损毁和去向。
4. 检查同时异地、恢复过快、消耗品无限和不可能行程。
5. 每项变化关联正文证据；大纲计划不得直接改正式状态。

**输出要求**：
故事时间线；人物位置表；状态表；物品流转表；连续性异常。

**限制与判断边界**：日期不明确时保留相对顺序，不编造精确时间。

## A10｜章节摘要与状态回写卡

**适用场景**：每章正文完成后

**任务目标**：把实际正文转成后续章节可依赖的结构化记忆。

**输入材料**：本章正式正文、章节任务卡和写前状态。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 概括正文实际发生的事件、选择、结果和代价。
2. 逐项核对必达事项，不将计划完成视为正文完成。
3. 提取人物、关系、地点、物品、设定和知情范围的变化。
4. 记录新埋与已回收伏笔，以及尚未解决的新问题。
5. 生成下一章必须承接的事项；所有正式变更附正文证据。

**输出要求**：
章节摘要；任务完成情况；状态变更；新增正文事实；伏笔变更；承接清单。

**限制与判断边界**：正文没有明确发生的计划不得回写为事实；含糊事件标为待确认。

## A11｜文风与视角偏移检测卡

**适用场景**：每章审校或风格异常时

**任务目标**：检测连续生成中的视角越界、人物同声和风格漂移。

**输入材料**：本章正文、风格规范、人物声纹、视角规则与参考章节。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 核对人称、视角人物和切换标记。
2. 找出视角人物无法看到、听到或知道的叙述内容。
3. 比较词汇、句长、叙述距离、解释密度和题材语感。
4. 对照人物声纹检查对话同质化，但保留情境导致的合理变化。
5. 只提交需要修复的位置和指令，不整体改写成单一腔调。

**输出要求**：
偏移位置；问题类型；对照依据；局部修订指令。

**限制与判断边界**：有意的视角实验和人物语言变化需结合创作意图判断。

## A12｜自动质量门禁卡

**适用场景**：正文完成后及归档前

**任务目标**：决定章节能否归档，并把问题转成明确返修任务。

**输入材料**：本章正文、章节任务卡、各专项检查结果和前后章衔接资料。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 检查设定、时间线、状态、信息边界等硬连续性。
2. 检查人物动机、剧情因果、章节任务完成度和前后衔接。
3. 检查重复信息、无效场景、节奏、高潮和章末钩子。
4. 汇总 A11 的视角与文风结果；必要时调用 A14。
5. 合并重复问题并分级，给出通过、返修或阻断结论。

**输出要求**：
门禁结论；P0/P1/P2 问题表；返修任务；可延后建议。

**限制与判断边界**：P0 阻断；P1 返修；P2 不阻断。不得为追求通过率降低既定标准。

## A13｜定向修订与回归复检卡

**适用场景**：门禁要求返修时

**任务目标**：以最小改动修复指定问题，并防止修订引入新矛盾。

**输入材料**：原正文、返修任务、不可变更事项、作品资料和前后章约束。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 锁定只需改动的场景和必须保留的内容。
2. 按问题依据修订，不顺手重写无关段落或改变作者风格。
3. 记录改动、原因及可能影响的状态和后文。
4. 重新检查原问题，再检查设定、状态、视角和衔接是否回归。
5. 两轮后仍有 P0 或 P1 时停止，保留版本并请求人工判断。

**输出要求**：
修订正文；变更说明；原问题复检；新增问题检查；剩余阻断项。

**限制与判断边界**：不得覆盖原稿记录；不得为修一处逻辑制造另一处冲突。

## A14｜事实、合规与原创风险检查卡

**适用场景**：涉现实专业事实、发布或高风险内容时

**任务目标**：处理作品内部资料无法确认的现实事实与发布风险。

**输入材料**：正文、故事年代地域、目标平台、专业领域及可获得的最新资料。调用时使用 `{{作品正文}}`、`{{作品设定}}`、`{{人物档案}}`、`{{故事大纲}}`、`{{前章摘要}}`、`{{用户要求}}` 等变量传入实际材料；不需要的变量可删除。

**执行指令**：
1. 区分现实事实、虚构设定和有意艺术加工。
2. 提取会影响剧情可信度的专业断言，并核验关键事实。
3. 需要时效信息时检索最新公开来源，记录实际依据。
4. 检查平台风险、现实影射及与既有作品异常近似的表达或桥段组合。
5. 将确定错误、争议内容、无法核实项分开，不保证平台审核结果。

**输出要求**：
风险位置；类型与级别；核验依据；修改方向；待人工确认事项。

**限制与判断边界**：无可靠依据时不得假装核验完成；不得凭感觉断言抄袭。
