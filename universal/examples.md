# 最小调用示例

示例用于接入后的冒烟测试，不要求模型逐字复现。应重点检查输入映射、输出结构和边界是否遵守。

## 示例一：AI 自动写作章节规划

### 调用卡片

A05｜章节任务与场景规划卡

### 输入

```text
{{故事大纲}}：第二卷中，沈砚需要取得旧港仓单，才能查出父亲失踪与商会有关。
{{前章摘要}}：沈砚刚被商会护卫逐出账房，右手受伤；盟友阿梨仍留在账房内，生死未明。
{{人物档案}}：沈砚谨慎，不会无准备硬闯；阿梨熟悉旧港水路。
{{伏笔台账}}：仓单编号“丁十七”已在第一卷出现，来源尚未解释。
{{目标字数}}：2500 字。
{{下一章约束}}：下一章开始时二人必须已经离开旧港。
```

### 预期输出结构

```text
章节任务卡：本章视角为沈砚；即时目标是找到阿梨并取得仓单。
场景顺序：撤离受阻 → 与阿梨会合 → 用既有信息换取仓单 → 带伤离开旧港。
必达事件：阿梨明确脱险；仓单到手；沈砚伤势被保留。
人物变化：沈砚从单独行动转为需要信任阿梨的安排。
信息释放：仓单与商会有关；不得解释父亲失踪的全部真相。
禁止泄露：不得让沈砚无来源知道阿梨的位置或账房密码。
章末钩子：仓单“丁十七”的登记人指向一个此前已建立的人物或势力。
验收重点：保留伤势与信息边界；本章结束后具备离开旧港的条件。
```

### 不合格表现

- 让沈砚毫无准备硬闯账房。
- 忘记右手受伤。
- 让角色突然知道自己无法获知的信息。
- 只写取得仓单，没有处理阿梨的处境或下一章离港约束。

## 示例二：人工稿件时间线核对

### 调用卡片

B06｜时间线与空间核对卡

### 输入

```text
{{作品正文}}：
周一清晨，陈岚从临川出发，乘马车前往三百里外的青岩。文中此前交代，这段路最快需要两天。
周一下午，陈岚在青岩客栈见到了已经等候她多时的师兄。
{{地理与行程设定}}：临川至青岩三百里，马车最快两天，中途无传送或替换交通工具。
```

### 预期输出结构

```text
级别：硬错误。
位置：第二段“周一下午，陈岚在青岩客栈……”。
问题：抵达时间早于既有行程规则允许的最早时间。
依据：周一清晨出发，三百里路程最快两天；无其他交通方式。
影响：会面事件在当前时间线下不能成立。
修改方向：推迟会面时间、提前出发时间，或在前文建立可信的快速行程方式；由作者选择。
置信度：确定。
```

### 不合格表现

- 没有引用原文与行程规则便直接判错。
- 擅自把马车改成快马或传送。
- 直接重写整段正文，而不是提供核对报告。

## 接入检查

1. 将变量名映射到系统字段，缺失的可选输入可以不传。
2. 检查模型是否遵守卡片权限：B 系列默认只读，A13 才可定向修订草稿。
3. 检查输出能否被下一张卡消费，例如 A05 的章节任务卡能传给 A07。
4. 若输出结构偏离，优先修正输入映射和提示词注入，不要在下游补造缺失状态。
