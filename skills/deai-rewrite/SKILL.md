# 去AI味改写

AI 痕迹的本质是**统计上的高频选择**：同样的情境，AI 反复选同一个词、同一种句式。本技能先量化扫描定位，再按规则改写，目标是"读者翻页时不会停下来想'这是AI写的'"。

## 工作流程

### 第 1 步：扫描定位

```bash
python {baseDir}/scripts/ai_tells_scan.py <文本文件> [--window 3000]
```

脚本按词表统计 AI 高频词的**出现次数与千字频率**，并标记超过阈值的词（阈值见 `references/ai-tells-zh.md`）。频率而非次数是判据——一万字里出现两次"仿佛"很正常，出现十五次就是病。

### 第 2 步：分类诊断

对超标项回读原文定位，按 `references/ai-tells-zh.md` 的六类归档：

1. **高频词滥用**：不禁、仿佛、眼底闪过一丝、嘴角勾起、空气凝固、心跳漏了半拍……
2. **三段式排比**："他恨、他怨、他不甘"式的三连结构
3. **空洞抒情**：没有信息量的感慨段（"命运的齿轮开始转动"式）
4. **解释型独白**：把读者能看懂的情绪再解释一遍（"他知道，这意味着……"）
5. **书面腔对话**：角色说话像写论文，无人称差异
6. **连接词臃肿**：然而、与此同时、紧接着密集出现

### 第 3 步：改写

改写规则（按优先级）：

1. **删优于换**：空洞抒情、解释型独白优先整句删，不是换同义词
2. **换词不如换写法**："眼底闪过一丝狠色"→ 改成具体动作（"他把茶盏搁下，没再接话"）
3. **排比拆成递进或留白**：三连结构保留最强的一拍，其余删掉或改写
4. **对话口语化**：按角色身份调整语域，加停顿、半截话、口语词
5. **保留一切剧情事实**：人名、设定、情节走向一字不动；只改表达方式

### 第 4 步：复扫验证

改写后再跑一遍 `ai_tells_scan.py`，确认超标项清零或降至阈值内。改写量与复扫结果一并报告。

## 质量标准

- **有据可依**：每处改写对应扫描命中或明确模式，不做无依据的大改
- **最小侵入**：能改一句不改一段，保留作者的句子骨架
- **改后不串味**：改写后的句子要像**这本书**的文风，不是像"正确的网文"——若用户提供 style-fingerprint 档案，以档案为准
- 报告改写统计：扫描命中数、改写处数、复扫结果；不要逐条罗列所有改动（量大时按类别抽样展示）
