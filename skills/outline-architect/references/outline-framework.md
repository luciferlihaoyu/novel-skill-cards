# 三线合一大纲框架

## 一、卷结构模板

每卷必填六项：

| 项 | 说明 | 反例 |
|---|---|---|
| 卷目标 | 主角这一卷要什么（具体、可达成、可失败） | "变强"（不可证伪） |
| 卷障碍 | 谁/什么挡路，为什么现在必须解决 | "很多敌人" |
| 卷末大爽点 | 一句话说清爽在哪 | "打败了敌人"（怎么爽？） |
| 升级台阶 | 本卷达成的力量/地位台阶 | — |
| 代价 | 主角失去了什么（没有代价的胜利不值钱） | 无代价全胜 |
| 钩子 | 卷末抛向下一卷的悬念 | 平收 |

卷数估算：免费平台长篇一卷 8-15 万字，付费平台 15-30 万字。总字数 ÷ 卷均字数 = 卷数，卷数定不下来就先定前三卷+终局，中间留弹性。

## 二、升级线设计

```
台阶表: 等级名称 | 达成章节 | 达成方式(绑定什么情节事件) | 新能力边界 | 代价
```

设计规则：

1. **可证伪**：每级写清"能做什么、不能做什么"，这将成为写作时的设定依据和完稿后的核对标准
2. **递增难度**：第 N+1 级所需代价/风险 > 第 N 级
3. **绑定事件**：升级必须长在情节上（战斗突破、顿悟、献祭），不接受纯时间流逝升级
4. **展示窗口**：每次升级后 3 章内安排一次"新能力展示"（小爽点），否则升级无感

## 三、伏笔台账

| 编号 | 伏笔 | 埋设章节 | 计划回收章节 | 跨度 | 中途提醒点 | 状态 |
|---|---|---|---|---|---|---|

- 跨度 > 50 章：安排 1 个提醒点；> 150 章：至少 2 个
- 回收方式分：正面回收（揭晓）、变体回收（伏笔变成了别的东西，需让读者意识到"原来如此"）
- 埋设原则：**埋的时候必须像闲笔**（一个物品、一句闲话），太郑重的伏笔读者会一直盯着等

## 四、节奏排期参数

| 参数 | 免费平台 | 付费平台 | 女频 |
|---|---|---|---|
| 小爽点间隔 | 1-2 章 | 3-5 章 | 情感进展可计为小爽 |
| 大爽点间隔 | 8-12 章 | 15-25 章（≈卷末） | 关系突破为大爽 |
| 连续压抑上限 | 2-3 章 | 4-6 章 | 视题材 |
| 章末钩子 | 每章 | 强弱交替 | 情绪钩为主 |
| 第一个爽点 | 前 3 章内 | 前 5 章内 | 前 3 章立住 CP 感 |

## 五、细纲自查清单

细纲排完后逐项过：

- [ ] 标出所有连续 ≥3 章无爽点的区间，能否插入小爽或重排顺序？
- [ ] 每个大爽点前是否有 ≥2 章铺垫（没铺垫的爽点不痛）？
- [ ] 连续两个大爽点之间是否有喘息章（疲劳检查）？
- [ ] 每卷末是否大爽点 + 下卷钩子双落位？
- [ ] 伏笔台账每条是否都有回收坐标或"待排期"标记？
