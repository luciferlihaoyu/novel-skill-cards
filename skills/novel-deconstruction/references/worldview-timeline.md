## 1. 世界观档案

| 项目 | 内容 | 依据章节 |
|---|---|---|
| 世界类型 | 修真 / 玄幻 / 都市 / 科幻 / 历史 / 无限流…… | |
| 时代与地点 | 主要地图(按出场顺序) | |
| 核心规则 | 世界运转的根本法则(灵气/魔法/科技/规则怪谈) | |
| 势力格局 | 主要势力及其关系(宗门/国家/公司/家族) | |
| 经济/资源系统 | 货币、修炼资源、稀缺品 | |
| 历史背景 | 上古秘辛、大事件(通常是后期伏笔) | |
| 地理结构 | 地图层级:新手村→区域→大陆→更高位面 | |

**信息投放评价**:世界观是靠"细节渗透"(好)还是"设定倾倒"(坏)?双背景文(如都市+仙侠)的高层背景是否提前锚定?

## 2. 力量/等级体系

- **等级表**:完整列出(如:炼气→筑基→金丹→元婴……),标注主角当前等级与升级章节
- **升级节奏**:主角每级停留多少章?前后期升级速度是否失衡(前期三级一年,后期一级百万年)?
- **战力标杆**:跨级挑战的合理性依据是什么?(功法/法宝/体质)
- **战力通胀**:后期是否出现"遍地大佬"导致前期设定贬值?

## 3. 设定自洽性检查(吃书检测)

> 本节侧重**跨卷/长篇**的设定漂移(吃书)。成稿前的强制一致性核对(数值算术、口径冲突、细节穿帮)统一按 `references/consistency-check.md` 执行,结果汇总进报告"文本矛盾清单"。

逐项核对并记录矛盾:

| 矛盾点 | 前文设定(章节) | 后文表现(章节) | 严重度 |
|---|---|---|---|
| 例:筑基寿元 200 年 | 第30章 | 第500章某筑基活了 300 岁 | 中 |

常见吃书高发区:
- 时间类:年龄、年限、闭关时长对不上
- 能力类:前期限制后期无故消失
- 资源类:前期稀世珍宝后期烂大街(无解释)
- 人物类:已死角色复活无交代、年龄/辈分错乱

## 4. 时间线梳理方法

**第一步:提取时间锚点**
- 明锚点:具体年月日、年龄、"三年后"、"翌日"等时间词
- 暗锚点:季节物候、节日、事件参照("大比之前")
- 顺序锚点:无明确时间时的相对顺序(章节顺序、人物行动线交叉)

**第二步:区分两种时间**
- **故事时间**(情节内经过的时间):识别时间跳跃("半年后")、时间流速异常(闭关/秘境/时差设定)
- **叙事时间**(文本呈现顺序):倒叙、插叙、多线并行的章节位置

**第三步:人物时间线交叉**
- 重要角色在同一故事时间的位置(用于发现"同一时间出现在两地"类穿帮)
- 多线叙事时,标注各线汇合章节

## 5. 时间线输出格式

### 主时间线表
| 序号 | 故事时间 | 章节 | 事件 | 涉及人物 | 备注(伏笔/矛盾) |
|---|---|---|---|---|---|
| 1 | 天玄历 3000 年春 | 1-3 | 主角灭门、跳崖 | 主角、灭门仇人 | 坠崖获传承(金手指来源) |
| 2 | 同年秋 | 4-10 | 拜入小宗门 | 主角、师父 | 时间跳跃 3 个月 |

### 辅助视图(按需)
- **卷级时间轴**:每卷的故事时长与章节占比(发现"一卷写三年 / 三卷写一天"的节奏失衡)
- **人物泳道**:同一故事时间内各主要人物在做什么
- **年龄推算表**:主角及各重要角色在关键节点的年龄(检测年龄穿帮)

**输出要求**:世界观档案表 → 等级体系表 → 吃书矛盾清单(如无则明确说明"未发现矛盾")→ 主时间线表(全书/指定范围)。

## 核对本五维度时必问的问题（Key Questions）
1. 这本书的核心世界规则是否前后自洽，有无吃书(设定漂移)？
2. 这本书的力量/等级体系是否清晰，升级节奏前后是否失衡？
3. 这本书的世界观信息是靠细节渗透还是设定倾倒？
4. 这本书的时间锚点(明/暗/顺序)能否提取，故事时间能否排成连续时间线？
5. 这本书是否存在"同一故事时间出现在两地"类的时间线穿帮与年龄错乱？
6. 这本书换地图/开新卷后，旧地图的设定与伏笔是否仍被遵守？

## 警示信号（Warning signals）
- 设定倾倒:大段说明书式介绍世界观,而非细节渗透（见上文 §1）
- 升级节奏失衡:前期数年升数级,后期百万年升一级（见上文 §2）
- 战力通胀:后期"遍地大佬",前期设定贬值（见上文 §2）
- 时间类吃书:年龄、年限、闭关时长前后对不上（见上文 §3）
- 能力类吃书:前期限制后期无故消失（见上文 §3）
- 资源类吃书:前期稀世珍宝后期烂大街且无解释（见上文 §3）
- 人物类吃书:已死角色复活无交代、年龄/辈分错乱（见上文 §3）
- 时间跳跃无标注,闭关/秘境时间流速前后不一致（见上文 §4）
- 同一故事时间内重要角色出现在两地（见上文 §4）
- 卷级节奏失衡:一卷写三年、三卷写一天（见上文 §5）
- 关键节点年龄推算对不上（年龄穿帮,见上文 §5）

## Agent 硬指令（Agent instruction）
1. 主时间线表每行必须含"故事时间+章节+涉及人物"三要素;缺章节号(第X章)的事件不得入表。
2. 吃书矛盾清单逐条写明"前文设定(第X章) vs 后文表现(第X章)"与严重度;未发现矛盾时明确写出"未发现矛盾",不得留空。
3. 输出等级体系表时标注主角每级停留章数;前后升级速度差超过一个数量级的,显式注明"升级节奏失衡"。
4. 年龄推算表覆盖主角与全部重要角色,对不上的标注"年龄穿帮(第X章 vs 第Y章)"。
