# 网文特有要素分析框架

> 网文区别于传统小说的商业要素:**爽点、期待感、金手指、平台调性**。拆书若只分析文学性而忽略这些,就失去了网文拆解的意义。

## 目录
1. 爽点体系
2. 期待感与追读设计
3. 金手指深度分析
4. 情绪节奏(AIDMA 视角)
5. 平台与商业化适配
6. 章节卡点和章末钩子

---

## 1. 爽点体系

**爽点类型清单**(分析时逐章标注):

| 类型 | 机制 | 经典场景 |
|---|---|---|
| 打脸 | 被轻视→实力反转→对方震惊/跪舔 | 拍卖会、宗门大比、退婚 |
| 升级/突破 | 数值与地位的可见成长 | 突破境界、获得职称 |
| 捡漏/夺宝 | 低成本获得高价值 | 地摊淘到神器 |
| 扮猪吃虎 | 隐藏实力→关键时刻爆发 | 路人嘲讽→一招秒 |
| 身份揭露/掉马 | 隐藏身份曝光,众人反应 | "他竟然是……" |
| 众人震惊 | 旁观者反应放大主角牛逼 | 长老们集体失态 |
| 复仇 | 前期受辱的清算 | 灭门之仇得报 |
| 感情 | 暧昧推进、关系确认 | 女主主动、情敌打脸 |
| 收获盘点 | 战利品清点(满足收集欲) | 清点储物袋 |

**分析维度**:
- 各类型占比(全书爽点结构饼图的文字描述)
- 爽点前的"压抑铺垫"是否充分(欲扬先抑:压抑越深,释放越爽;但压抑超 10 章易弃书)
- 爽点是否升级(同一个打脸套路重复 5 次以上 → 疲劳)

## 2. 期待感与追读设计

读者追更靠"期待感"而非单纯爽。识别作者使用的期待感装置:

- **目标预告**:主角明示下一阶段目标("三个月后宗门大比")
- **危机悬置**:威胁已出现但未爆发(仇家正在追查)
- **倒计时**:明确期限制造紧张(丹药只能压制毒性 30 天)
- **能力半展示**:金手指只露一角,读者期待完全体
- **多线悬念**:A 线危机时切到 B 线(章末换线 = 强制追读)
- **信息不对称**:读者知道而角色不知道(或反之)

**分析产出**:列出全书/本卷的"期待感链条"——每个悬置的问题在第几章被解答,解答前是否又抛出新问题(问题链不能断)。

## 3. 金手指深度分析

```
【金手指档案】
名称/形态:
获得方式与章节:
核心功能:
限制与代价:(无限制金手指是后期崩盘头号原因)
成长性:是否随剧情解锁新功能?
使用频率:每 N 章使用一次?(过度依赖 → 主角废物化)
与主线关系:金手指是否即主线?(系统流:系统是任务发布器 = 主线引擎)
```

**常见流派判定**:系统流 / 签到流 / 模拟器流 / 老爷爷流 / 重生先知流 / 天赋体质流……并评价该金手指在同流派中的创新度。

## 4. 情绪节奏(AIDMA 视角)

> 用法:AIDMA 是诊断工具而非填空模板——用于定位情绪设计的缺口;逐条机械对号(每步找一句话贴上)不产生洞察,无缺口时一句话带过即可。

比"黄金三章"更底层的框架——读者情绪设计:

1. **Attention 注意**:开篇钩子是否 3 秒内抓眼?
2. **Interest 兴趣**:设定/人物是否产生好奇?
3. **Desire 欲望**:读者是否产生"想看主角赢"的欲望?(压抑与期待制造)
4. **Memory 记忆**:有无记忆点场面/名台词/名场面?
5. **Action 行动**:追更/打赏/推荐的驱动力在哪?

**情绪曲线绘制**:按卷/按 10 章为单位,标注情绪值(压抑 -5 ~ +5 释放),观察:
- 曲线是否波浪起伏(健康)还是长期平躺(劝退)
- 大高潮是否出现在卷末(标准商业结构)

## 5. 平台与商业化适配(可选维度)

若已知目标平台,对照平台调性分析:
- **起点**:老白读者,重设定、重逻辑、慢热可活
- **番茄/七猫(免费)**:下沉市场,强情绪、快爽点、首章定生死,完读率是核心指标
- **晋江**:感情线权重高,人设与 CP 感优先
- **知乎盐选**:短篇,第一人称,强反转,开篇即高潮

**输出**:判定该书最适合的平台及理由;若为免费平台,重点评估"首章读完率"要素(前 300 字钩子、首章内小高潮)。

## 6. 章节卡点与章末钩子

网文按章付费/按章留存,**章末钩子**是核心技术:
- 逐卷抽查章末,分类钩子类型:危机型(刀架脖子上结束)/ 悬念型(神秘人出场)/ 反转型(身份揭露一半)/ 期待型(大战一触即发)
- 统计"平收尾"章节比例(平收尾 = 追读流失点)
- 关键卡点(上架第一章、卷末、百章整数关)是否有特别设计?

**输出要求**:爽点类型分布 → 期待感链条 → 金手指档案 → 情绪曲线描述 → 平台适配判断 → 章末钩子抽查报告。
