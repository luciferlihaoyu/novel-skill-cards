## 2. 主角分析

- **人设类型**:冷静理性 / 热血莽撞 / 苟道稳健 / 腹黑算计 / 逗比吐槽……(识别类型,并找出"定人设"的关键场景)
- **代入感设计**:主角的什么特质让读者代入?(废柴出身 / 现代思维 / 被欺压的处境)
- **行为一致性**:主角行为是否前后一致?有无"为了剧情强行降智"的章节?
- **成长线**:实力成长(等级表)与心智成长(观念变化)是否双线并行?还是只有数值膨胀?
- **金手指分析**:金手指是什么?代价/限制是什么?(无代价金手指 → 后期崩盘风险)何时获得?使用频率?

## 3. 配角与反派分析

- **配角功能性判定**:
  - 助力型(给资源/给情报)/ 阻力型 / 见证型(震惊反应担当)/ 感情型 / 搞笑型
  - 工具人比例:有多少配角出场即完成任务、再无下文?
- **反派质量**(决定书的上限):
  - 动机是否成立?(为坏而坏 = 低质反派)
  - 智商是否在线?(给主角送人头的反派 = 拉低全书)
  - 层级设计:小反派 → 中反派 → 大 BOSS 的升级链是否清晰?
- **女主/男主(感情线)**:何时登场?感情推进节点表(初遇/改观/定情/波折)?是剧情参与者还是花瓶/挂件?

## 4. 人物关系网

用文本关系图呈现核心关系(标注关系性质与变化):

```
韩立 —[师徒·利用→敬重]→ 墨大夫(第X章关系反转)
韩立 —[道侣]→ 南宫婉(第X章初遇 → 第X章定情)
韩立 —[宿敌]→ 王蝉(第X章结怨,贯穿X卷)
```

- **关系即戏**:哪些关系天然产生冲突/张力?(扭曲的关系比单纯的冲突更抓人)
- **关系变化表**:关键关系在哪几章发生质变?触发事件是什么?
- **阵营划分**:势力图谱(主角阵营 / 敌对阵营 / 中立摇摆),随卷推进如何演变?

## 5. 人设常见问题清单(诊断用)

- [ ] 主角无鲜明记忆点,换个人名故事照样成立
- [ ] 配角超过 5 个同时出场且名字相似(读者混淆)
- [ ] 反派智商全员下线,只为送经验
- [ ] 女性角色全员倒贴/花瓶,无独立动机
- [ ] 重要角色长期"失踪"(几十章无交代)
- [ ] 人设崩坏:前期冷静苟道,后期突然莽撞(无铺垫转变)
- [ ] 角色说话一个腔调(遮住名字分不清谁在说)

**输出要求**:主角深度分析 → 重要人物档案卡(≤8 人)→ 反派评价 → 关系网图 → 问题诊断与改进建议。

## 核对本五维度时必问的问题（Key Questions）
1. 这本书的主角人设是否有记忆点，换一个人名故事是否照样成立？
2. 这本书的主角行为是否前后一致，有无"为剧情强行降智"的章节？
3. 这本书的反派动机与智商是否在线，小反派→大 BOSS 的升级链是否清晰？
4. 这本书的配角是否各有功能，出场即消失的工具人占比是否过高？
5. 这本书的感情线角色是否有独立动机与剧情参与度，还是花瓶/挂件？
6. 这本书的关键关系是否发生质变，且每次质变都有触发事件与章节可查？

## 警示信号（Warning signals）
- 主角为剧情需要强行降智,行为前后不一致（见上文 §2）
- 金手指无代价/无限制,埋下后期崩盘隐患（见上文 §2;金手指详档另见 webnovel-elements §3）
- 成长只有数值膨胀,心智成长线缺位（见上文 §2）
- 反派为坏而坏、智商全员下线,只为给主角送经验（见上文 §3、§5）
- 女性/感情线角色全员倒贴或花瓶化,无独立动机（见上文 §3、§5）
- 配角出场即完成任务再无下文,工具人比例过高（见上文 §3）
- 重要角色几十章"失踪"无交代（见上文 §5）
- 人设崩坏:前期冷静苟道后期突然莽撞,转变无铺垫（见上文 §5）
- 角色说话一个腔调,遮住名字分不清谁在说（见上文 §5）
- 5 个以上配角同时出场且名字相似,读者混淆（见上文 §5）
- 大段外貌描写堆砌而无记忆点（见上文 §1）
- 主角无鲜明记忆点,换人名故事照样成立（见上文 §5）

## Agent 硬指令（Agent instruction）
1. 每张人物档案卡的"性格核心"必须附书中依据(第X章的具体行为);给不出依据的标注"依据不足",不得凭印象概括。
2. 关系网图每条关系标注关系性质与质变章节(第X章);全书无质变的写"未质变"。
3. 反派评价必须分别给出"动机是否成立"与"智商是否在线"两个独立结论,禁止合并为一句笼统评语。
4. 输出问题诊断时逐项对照 §5 清单,命中条目必须给出章节证据;全未命中也要明写"§5 清单零命中"。
