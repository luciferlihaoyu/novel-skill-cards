# 情节结构与脉络分析框架

> 用于拆解全书/分卷的情节走向、主线结构、节奏设计与高潮分布。

## 目录
1. 故事梗概(第一步必做)
2. 主线/支线结构
3. 情节阶段划分(起承转合)
4. 节奏与爽点分布
5. 伏笔与回收
6. 情节套路识别

---

## 1. 故事梗概(先梗概后分析)

先用 300-500 字概括:
- **故事背景**:时代、地点、世界类型
- **主要人物**:主角及其目标、动机
- **核心冲突**:主角想要什么 × 什么在阻止他
- **发展线索**:按时间顺序的主要情节走向

## 2. 主线/支线结构

- **主线识别**:全书的核心驱动力是什么?(升级/复仇/解密/感情/争霸……)
- **支线清单**:列出主要支线(感情线、副 CP、配角线、势力线),标注其与主线的关系(服务主线 / 独立成章 / 注水嫌疑)
- **结构图建议**:用文本树或表格呈现:
  ```
  主线:废柴逆袭成帝
  ├── 支线1:与女主的感情(服务主线,提供动机)
  ├── 支线2:宗门内斗(中期主要冲突容器)
  └── 支线3:身世之谜(暗线,后期引爆)
  ```

## 3. 情节阶段划分

按实际阅读划分阶段(长篇网文通常按"卷"或"地图/副本"切换):

| 阶段 | 章节范围 | 核心事件 | 冲突 | 功能 |
|---|---|---|---|---|
| 开篇 | 第1-3章 | … | … | 立人设、抛钩子 |
| 铺垫 | … | … | … | 蓄力、压抑/期待 |
| 第一个高潮 | … | … | … | 首次情绪释放 |
| 转折 | … | … | … | 重大决策/变故 |
| 中段高潮 | … | … | … | 最大冲突解决 |
| 收束/新循环 | … | … | … | 换地图/开新篇 |

**关键标注**:
- **高潮点**:冲突如何解决?重大决策如何做选择?最紧张的段落怎么写的?
- **转折点**:全书/本卷的重大转折在哪一章?由什么事件触发?
- **情绪曲线**:压抑段与释放段的交替频率(网文常见"三章一小爽,十章一大爽")

## 4. 节奏与爽点分布

- **爽点类型标注**(逐章或逐卷):打脸、升级、捡漏/夺宝、身份揭露、众人震惊、感情进展、复仇得逞
- **密度统计**:爽点间隔多少章?有无连续 10 章以上无释放的"劝退段"?
- **期待感设计**:作者如何让读者期待下文?(目标预告 / 危机悬置 / 倒计时 / 能力展示一半)
- **水文识别**:占比多少章节属"循环套路"(下副本→打脸→收获→换地图)而无实质推进?

## 5. 伏笔与回收

建立伏笔台账:

| 伏笔 | 埋设章节 | 内容 | 回收章节 | 状态 |
|---|---|---|---|---|
| 神秘老者身份 | 第12章 | … | 第340章 | ✅已回收 |
| 断剑来历 | 第45章 | … | — | ❌未回收(断更/遗忘) |

- 长线伏笔(贯穿全书) vs 短线伏笔(卷内回收)
- 楔子/引子与后文的呼应关系

## 6. 情节套路识别

识别该书使用的经典网文套路/流派并评价其执行与创新:
- **流派**:凡人流、废柴流、无敌流、重生流、系统流、签到流、苟道流、无限流、规则怪谈……
- **桥段库**:退婚、拍卖会、宗门大比、秘境夺宝、越级挑战、扮猪吃虎、马甲掉落……
- **评价**:是模板化执行(看到前面猜到后面)还是套路内创新?反套路设计是否成立?

**输出要求**:梗概 → 主线支线结构 → 阶段表 → 爽点分布统计 → 伏笔台账 → 套路判定与评价。
