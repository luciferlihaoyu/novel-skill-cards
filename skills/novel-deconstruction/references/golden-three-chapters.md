# 黄金三章分析框架

> 黄金三章 = 小说开篇前三章,决定读者留存与签约命运。约 90% 的读者在前三章内决定是否弃书;编辑审稿也以前 5000 字的核心冲突出现与否为初筛标准。
> 注意:黄金三章是经验法则而非铁律(网文界对其有争议,如《凡人修仙传》开头平淡靠后文翻盘)。分析时既要按框架拆解,也要评估其"变体"是否自洽。

## 1. 逐章拆解清单

### 第一章(留住人,约 3000 字内完成)
- [ ] **开篇即冲突/悬念**:是否在开头 500 字内抛出核心钩子?还是大段背景/景色铺垫?
- [ ] **主角登场即立住**:主角何时出场?通过什么"选择/行为"展示性格?(面对危机求饶/怒骂/冷静观察 = 不同人设)
- [ ] **世界观锚点**:是否通过环境细节自然渗透(如"断头台/监斩官/魔门"暗示修真世界),而非说明书式介绍?
- [ ] **人物数量控制**:前三章出场有名字的人物是否 ≤5 个?(过多名字读者记不住)
- [ ] **章末钩子**:第一章结尾是否留有悬念/危机/反转,驱使用户点下一章?

### 第二章(立期待)
- [ ] 主线方向是否明确?(读者能否说出"这本书要讲什么")
- [ ] 金手指/核心设定是否亮出或暗示?
- [ ] 矛盾是否升级而非原地踏步?

### 第三章(定去留)
- [ ] 是否完成第一个小高潮或情绪释放?
- [ ] 是否抛出贯穿前期的大悬念/大目标?
- [ ] 三章合看:节奏是否一环扣一环,有无拖沓段落?

## 2. 钩子(Hook)分析

识别开篇使用的钩子类型(可叠加,多重钩子更强):

| 钩子类型 | 说明 | 示例信号 |
|---|---|---|
| 死亡/生存危机 | 开场即绝境 | 断头台、追杀、绝症 |
| 身份错位 | 穿越/重生/夺舍/掉马 | "我不是这个世界的人" |
| 反差 | 身份与处境强烈不符 | 亿万富翁住贫民窟 |
| 悬念提问 | 隐藏关键信息 | "她打开信封,脸色苍白" |
| 倒叙 | 从结局/高潮切入 | "他站在法庭上,回想那个夜晚" |
| 情感冲击 | 强烈情绪场景 | 背叛、失去、屈辱 |
| 诡异悬念 | 反常现象 | 月圆之夜孤儿院的哭声 |

**分析要点**:钩子在第几段出现?出现前有多少"废话"?钩子是否在三章内得到部分兑现(只吊不喂 = 流失)?

## 3. 冲突与悬念分析

- **冲突层级**:外部冲突(人与人/与环境)/ 内部冲突(内心挣扎)——开篇以外部冲突为佳
- **冲突升级线**:三章内冲突是否逐级加码?(小冲突 → 中冲突 → 大冲突预告)
- **悬念设置手法**:隐藏关键信息 / 制造不确定性 / 倒叙 / 多线伏笔
- **铺垫与释放比**:欲扬先抑是否成立?(没有铺垫的爽点不成立;只抑不扬 = 弃书)

## 4. 信息投放节奏

检查"总分结构":吸引点先行,背景后补。
- ✅ 正面信号:语言简洁直白、每段都有推进、背景靠细节渗透
- ❌ 反面信号:已归拢至文末"警示信号"一节(原"大段设定说明/童年流水账/穿越前铺垫过长"三条)

**开篇五种经典模式**(识别该书属于哪种):
1. 先抑后扬(废柴流/凡人流):开头压抑,后期爬坡,代入感强
2. 先扬后抑(天才转废柴):失落跨度大,前世经验作金手指
3. 复仇报恩:动机直接
4. 烘托法:主角迟出场,所有描写为引出主角(如《枭臣》)
5. 楔子伏笔法:引子点出全书最大伏笔/高层背景

## 5. 评分量表(每项 1-5 分,附依据)

| 维度 | 1 分(差) | 5 分(优) |
|---|---|---|
| 钩子强度 | 前 1000 字无钩子 | 首段多重钩子叠加 |
| 主角立人设 | 工具人、无记忆点 | 一个选择/细节立住性格 |
| 冲突节奏 | 三章无冲突或原地踏步 | 逐级升级、环环相扣 |
| 信息效率 | 大段设定/童年流水账 | 细节渗透、零废话 |
| 章末悬念 | 平淡收尾 | 每章末都有追读动力 |
| 商业潜力 | 编辑 5000 字内弃稿 | 签约相/完读率预期高 |

**输出要求**:逐章拆解 → 钩子清单 → 模式判定 → 量表评分 → 3 条可操作的改进建议(若用于改稿)。

## 核对本五维度时必问的问题（Key Questions）
1. 这本书的开篇钩子是否在首段或前 500 字内出现，且在三章内得到部分兑现？
2. 这本书的主角是否在第一章就通过一个选择或行为立住人设？
3. 这本书前三章的冲突是否逐级升级、环环相扣？
4. 这本书的信息投放是否"吸引点先行、背景后补"，有无大段设定说明或流水账？
5. 这本书每一章末尾是否都有驱动追读的悬念/危机/反转？
6. 这本书的开篇模式（五种经典模式之一）是否自洽，其"变体"是否成立？

## 警示信号（Warning signals）
- 前 1000 字无钩子，以大段背景/景色铺垫开篇（见上文 §1、§5 量表）
- 童年流水账开篇（仅当出生异象即金手指、可作楔子时豁免）（见上文 §4）
- 穿越前铺垫超 5000 字且与穿越后剧情无关（见上文 §4）
- 钩子只吊不喂：三章内零兑现，读者期待落空（见上文 §2）
- 前三章出场有名字人物 >5 个，读者记不住（见上文 §1）
- 三章冲突原地踏步、无升级线（见上文 §3、§5 量表）
- 章末平淡收尾，无悬念/危机/反转（见上文 §1、§5 量表）
- 前 5000 字核心冲突未出现（编辑初筛红线）（见上文引言、§5 量表）

## Agent 硬指令（Agent instruction）
1. 输出评分表前，第 1 章至少摘出一个原文钩子句作为依据；摘不出即注明"第 1 章未构建钩子"并按量表扣分。
2. 逐章拆解必须标注每章章末钩子的有无与类型（引用到第X章末段）；平收尾要明写。
3. 判定开篇模式（五种经典模式之一）须给出至少一处原文证据；证据不足写"模式不明"，不得悬空评价。
4. 所有评分与结论必须附"第X章"依据，禁止无章节号的悬空定性。
