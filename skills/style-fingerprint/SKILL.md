# 文风指纹

目标：把"这本书读起来是什么味儿"变成一份**可执行的档案**，让任何后续写作（人工或 AI）都能对齐。文风不是形容词堆砌（"文笔老练""画面感强"），而是可测量的习惯：句长怎么分布、对话怎么写、爱用什么词、段落什么形态。

## 工作流程

### 第 1 步：取样

- 单文件直接用；长篇取 3-5 个样本段（开头一卷 + 中段高潮 + 最新章节），总样本 1-3 万字为宜
- 续写任务：优先取**续写点之前最近的 2-3 章**，越近文风越相关

### 第 2 步：客观测量

```bash
python {baseDir}/scripts/style_profile.py <文本文件或目录> --out style_profile.json
```

脚本输出：句长分布（短/中/长句占比、平均句长）、对话占比、段落长度分布、标点习惯（感叹号/省略号/破折号频率）、高频实词 Top 50、高频开头字。**数据是骨架，还需要你回读原文补上血肉。**

### 第 3 步：定性补全

回读样本，补充脚本测不出的维度：

- **叙述视角与人称**：第几人称、是否贴主角视角、视角切换习惯
- **对话风格**：对话是否带动作/神态描写、台词长短、口语化程度、有无口癖
- **修辞倾向**：比喻多不多、爱用什么意象、白描还是浓墨重彩
- **情绪写法**：情绪直给（"他怒了"）还是动作外化（"他捏碎了杯子"）
- **节奏偏好**：长短句如何交替、爱不爱用短句独立成段制造张力
- **标志性句式**：反复出现的结构（排比、反问、XX 的 XX 式短语）

### 第 4 步：输出文风档案

档案包含四层，按此顺序：

1. **一句话定调**：用作品类比定位（"偏起点白描快节奏""偏晋江细腻情感流"）
2. **客观指标表**：脚本测量结果的关键数字（句长、对话占比等）
3. **写作习惯清单**：10 条以内可执行的"这样写才像它"规则，每条配原文例句
4. **禁区清单**：这本书**不会**出现的写法（如"从不用比喻""绝不大段心理独白"），防止续写串味

档案保存为 Markdown 文件。使用时把它附在续写/改写提示里即可。

## 质量标准

- 每条习惯规则必须有原文例句佐证，禁止空泛的"文风优美"
- 区分**作者习惯**与**题材共性**（"升级打怪"是题材不是文风）
- 档案控制在两页以内，续写时能被完整带上；超过就砍，保最独特的特征
- 同一作者多本书差异大时分别建档，不强行合并
