# 开篇打磨器

黄金三章决定一本书的生死：免费平台读者给一本书的耐心通常不到一章。开篇要解决的不是"把故事背景交代清楚"，而是**让读者在 3000 字内认定"这本书的主角值得我跟"**。

## 工作流程

### 第 1 步：判定任务类型

- **新开篇设计**：从创意/大纲出发，产出前三章的切入方案与逐章设计
- **已有开篇诊断**：按第 3 步的验收清单逐项检查，出"留存风险报告"+ 重写方案

### 第 2 步：确定切入点（最关键的一步）

切入点选择原则，按优先级：

1. **从变动开始**：主角生活被打破的那一天/那一刻，不从日常写起（"林炎被退婚那天"优于"林炎从小如何如何"）
2. **从冲突中段切入**（in medias res）：开场即对峙/危机/羞辱现场，背景用动作缝隙补
3. **主角必须是第一章的绝对焦点**：第一章出场的有名角色 ≤ 4 个，主角视角不离开

明确否决的开局（用户坚持用也要标注风险）：大段世界观说明开局、群像开局、梦开局、前世回忆录开局（倒叙交代死亡可以，连续两章回忆不行）。

### 第 3 步：逐章设计与验收

加载 `references/golden-three-framework.md`，按硬框架设计/验收：

| 检查项 | 合格线 |
|---|---|
| 主角登场 | 第 1 章前 500 字内，且有动作/处境而非简历式介绍 |
| 核心困境 | 第 1 章内立住（他被退婚/被追杀/快死了） |
| 金手指/卖点 | 前 3 章内亮相并演示一次 |
| 第一个爽点 | 前 3 章内兑现（可以小，必须有） |
| 章末钩子 | 每章末都有，且第 1 章末必须是强钩 |
| 信息密度 | 前 3 章无整段背景说明；设定随事件带出 |
| 情绪线 | 困境→获得筹码→小兑现，形成第一个完整期待循环 |

### 第 4 步：交付

- 新设计：切入方案（2-3 个备选，附各自风险）→ 选定后出前三章逐章细纲（每章：场景、冲突、信息投放清单、章末钩子）
- 诊断重写：留存风险清单（按严重度）→ 重写方案（改哪里、怎么改，必要时给出第 1 章开头 500 字的示范改写）
- 用户要求直接写正文时，按细纲写，遵守本书文风（有 style-fingerprint 档案则挂上）

## 质量标准

- **每个设计决策都要能回答"这留住了读者哪根神经"**
- 开篇与后续大纲必须咬合：金手指的能力边界与 outline-architect 的升级线一致，避免开篇即天花板
- 第一章写不满"困境+主角性格+钩子"三件事之前，不允许引入第二个场景
- 诊断时不留情面：开篇问题是全书中唯一"宁改十遍不可将就"的部分
