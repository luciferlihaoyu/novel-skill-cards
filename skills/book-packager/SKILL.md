# 文案包装卡

免费平台上，书名+简介决定 80% 的点击率；简介前 50 字决定简介的完读率。包装的本质是**把书的卖点翻译成读者三秒内能消化的承诺**。本技能与正文写作是完全不同的功夫：这里允许夸张、允许套路、唯独不允许平淡。

## 工作流程

### 第 1 步：提炼卖点（包装的地基）

从用户的书（大纲/开篇/已有正文）中提炼三个原料：

1. **核心爽点**：读者看这本书图什么（打脸？升级？甜宠？权谋？）
2. **差异化钩子**：和同类书比，这本独有的是什么（反套路设定/特殊金手指/新鲜组合）
3. **目标读者画像**：谁会为这本书停下来（决定文案的语气与用词）

提炼不出差异化钩子时直接告诉用户：这是书的问题不是文案的问题，文案只能放大卖点，不能无中生有。

### 第 2 步：按平台范式产出

加载 `references/platform-styles.md`，确认目标平台后按对应范式输出**每类 3-5 个候选**：

- **书名**：免费平台风（直给型/反差型）/ 付费平台风（意象型/概念型）/ 女频风
- **简介**：按"前 50 字钩子 + 中段放大期待 + 结尾承诺"三段式，每套附字数
- **标签**：主标签 + 副标签组合，注明每个标签的流量属性与竞争度常识
- **前 5-10 章章节名**：免费平台可当半个钩子用，付费平台按风格统一

### 第 3 步：输出与比选

每个候选附**点击逻辑**一句话（它勾的是读者的哪种心理：好奇/爽感预期/身份代入/CP 期待），并给出"如果只能选一套"的推荐及理由。用户拿不定主意时，建议 A/B 测试方案（先上候选甲，观察 24-48 小时数据再换）。

## 质量标准

- **简介不许剧透关键反转**，但必须让读者预见到爽点类型（"图什么"要明示）
- 书名候选必须过三查：撞名查（与站内热门书撞名直接出局）、朗读查（念出来不拗口）、搜索查（生僻字影响搜索的标注风险）
- 文案承诺必须与正文兑现一致——"无敌流"文案配憋屈正文是读者流失最快的方式；发现承诺与正文不符时指出，让用户选：改文案还是改正文
- 套路段子可以俗，但不能假：禁止编造正文里不存在的情节进简介
