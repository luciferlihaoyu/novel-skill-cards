# 网文节奏分析框架

## 期待账簿模型

把读者期待当成账目：**铺垫 = 存入期待，爽点 = 兑现期待，钩子 = 展期期待**。

- 只存不取 → 憋屈弃书（压抑过长）
- 只取不存 → 爽点贬值（没有铺垫的打脸不痛）
- 健康节奏：存取交替，大额期待（主线悬念）分期兑现，小额期待（章节级）快速兑现

诊断时逐章记账：本章存入了什么（新冲突/新悬念/新目标），兑现了什么（打脸/突破/收获）。

## 爽点类型与强度

| 类型 | 典型场景 | 强度 |
|---|---|---|
| 打脸 | 被轻视者当众证明自己 | 中-大（视铺垫长度） |
| 实力提升 | 突破境界、获得功法 | 中 |
| 收获 | 宝物、财富、资源到手 | 小-中 |
| 身份揭露 | 马甲掉落、真香现场 | 大 |
| 情感进展 | 关系突破、羁绊加深 | 小-中（视题材权重） |
| 危机解除/反杀 | 绝境翻盘 | 大 |

强度原则：**铺垫越久，兑现必须越大**；大爽点之后要给小喘息（日常/过渡），连续大爽会疲劳。

## 节奏诊断规则

1. **爽点荒**：免费平台连续 3 章无爽点即预警，5 章高危；付费平台可放宽至 5-8 章
2. **铺垫段**：单一冲突的铺垫不宜超过 3-5 章；超过则需在中途给小兑现（阶段性打脸/小收获）
3. **高潮写法**：大爽点至少给足一整章，分"压制→蓄力→爆发→余韵"四拍；一章秒完或余韵被下章开头立刻打断 = 泄气
4. **章末钩子**：连续 3 章以上平收（无悬念无危机无期待）即预警
5. **水文区**：连续 2 章以上既不存入期待也不兑现期待 = 水；判定前检查是否有隐藏功能（塑造人物/埋设定），有则降级为"偏慢"

## 黄金三章专项检查

- 第 1 章：主角与核心困境是否出场？章末是否有钩子？
- 金手指/核心卖点是否在前 3 章内亮相？
- 第 1 个爽点是否在前 3 章内兑现（哪怕小）？
- 无效信息排查：大段背景设定、与主线无关的人物群像、慢热风景描写

## 平台差异速查

| 平台类型 | 爽点密度 | 开篇要求 | 卡点要求 |
|---|---|---|---|
| 免费（番茄/七猫类） | 高，1-2 章一小爽 | 第 1 章必须出冲突 | 每章必卡 |
| 付费（起点类） | 中，允许铺垫 | 前三章立住卖点 | 关键章卡 |
| 女频（晋江类） | 情感进展可计入爽点 | 人设与CP感优先 | 情绪卡点为主 |
