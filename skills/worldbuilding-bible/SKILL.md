# 设定集构建器（世界观圣经）

设定集的唯一验收标准：**写正文时查它就够了，不用翻前文**。所以本技能的所有产出都遵守两条铁律——每条规则可证伪（能被"违反了吗"检查），每个设定带边界（能做什么 + 不能做什么）。

## 工作流程

### 第 1 步：定模式

- **前置模式**（新书）：从题材与创意出发，自上而下搭建设定集
- **收拢模式**（在写的书）：从已写章节里提取设定，填进模板，空缺处标注"未定"，冲突处直接列出请作者裁决——收拢时**忠实记录原文，不替作者脑补**

### 第 2 步：分模块构建

复制 `assets/bible-template.md`，按模块填写。模块取舍由题材决定（都市文不需要修炼体系，科幻不需要宗门），不需要的模块删除而非留空。核心模块：

1. **力量体系**：等级表，每级四要素——名称、能力边界（能/不能）、达成条件、社会对应地位。力量体系的第一原则：**层级之间的碾压关系要明确**（高一级对低一级意味着什么），模糊的层级会让所有战斗戏失去张力
2. **势力格局**：每个势力的地盘、首脑、核心诉求、与其他势力的关系（同盟/敌对/附庸）。势力必须"想要什么"，静态的势力只是背景板
3. **地理**：地图层级（世界→洲/域→国→城），附关键地点之间的距离与行程时间（时间线核对的依据）
4. **经济**：货币单位与购买力锚点（"一枚灵石≈一户人家几个月开销"这种可计算的锚点）
5. **历史**：只写**会在正文里被提及**的历史，不写自嗨编年史
6. **规则与例外**：世界的硬规则（"死者不可复生"）及其已设计的例外——例外必须提前登记，后面临时加例外就是吃书

### 第 3 步：自洽性预检

填完模板后自查：

- **数值闭环**：经济锚点 × 时间 = 的量级与力量体系消耗是否兼容（修炼一天烧多少钱，主角供得起吗）
- **力量天花板**：体系顶层是否预留了主角到达前的剧情空间
- **冲突源**：势力之间的诉求是否天然打架（都打不起来的势力图没有戏剧价值）
- 发现的自相矛盾直接在文中修正，并在文末"修订记录"注明

### 第 4 步：交付与维护

- 输出 Markdown 设定集文件；前置模式下未定的条目用 `【未定】` 标记集中列在文末
- 写作过程中设定集是**活文档**：正文新增的设定回写进设定集，设定集与正文冲突时以修订记录注明哪侧为准

## 质量标准

- 每个等级/势力/规则都带"边界"或"诉求"，纯描述性设定（只有名字和形容词）视为未完成
- 宁可模块少而实，不可模块全而空
- 命名风格统一（必要时配合 name-forge 生成），同一体系内不出现画风跳脱的名字
