# 设定一致性检查（穿帮猎手）

把长篇小说当成一个**事实数据库**来审计：先把散落在各章的可证伪事实收拢成清单，再让事实互相碰面，找出矛盾。穿帮的高发原因不是没读到，而是两个事实分别记在不同章节、从未被放在一起比对——本技能的核心就是强制让它们碰面。

## 工作流程

### 第 1 步：切分章节（必须）

小说动辄几十万字，先切分建立章节索引：

```bash
python {baseDir}/scripts/chapter_splitter.py <小说文件> --out-dir <工作目录>
```

产出 `chapter_index.json`（章节号/标题/字数）与单章文件。无法识别章节标题时按字数切块，并在报告中注明"按字数块分析"。支持 txt；docx/pdf 先转纯文本再切分。

### 第 2 步：建立事实清单

逐章（长篇按"每卷开头+高潮章+卷末"抽样，注明抽样率）提取**可证伪的事实**，每条带章节号与原文摘录，按五类归档：

| 类别 | 提取什么 | 例 |
|---|---|---|
| 数值规则 | 一切可计算的量：升级所需经验、丹药效果、价格、税率、冷却/持续时间、距离与行程天数 | "练气三层升四层需凝露丹三枚" |
| 设定口径 | 同一事物的定义性描述：境界划分、功法层级、组织架构、地名归属 | "青云宗下辖七峰" |
| 细节连续 | 人物外貌、伤势、随身物品、所在位置、持有物数量 | "左臂被斩断" |
| 生死下落 | 每个有名角色的最新状态：生/死/失踪/所在地点 | "赵长老闭关三年" |
| 伏笔承诺 | 明确埋下的钩子：神秘物件、未解之谜、约定了的事 | "三年后白云山之约" |

提取规则：**宁多勿漏，只记原文说的**；推断出来的不算事实，但可另列"存疑推断"。

用检索定位比对目标（比全文重读快得多）：

```bash
python {baseDir}/scripts/anchor_grep.py <工作目录> "凝露丹"
```

### 第 3 步：三层核对（强制，逐条执行）

加载 `references/check-dimensions.md`，对事实清单做三层核对：

1. **数值算术**：规则 × 时间/次数 ≠ 文中声称的结果（例：每日产出 10 灵石 × 30 天 = 300，文中却写"攒下五百灵石"）
2. **设定口径**：同一事物出现两种说法（例：第 12 章"七峰"，第 88 章"九峰"）
3. **细节连续**：同一事件/物体/状态的描述前后变化且无解释（例：断的是左臂，后文"他抬起右手摸了摸断臂处"——若右臂完好则成立，若前文右臂亦伤则矛盾）

时间线单独处理：从章节索引 + 时间词（"三日后""半月""次年开春"）推算每条时间锚点，累加校验总时长是否与文中声称一致。

### 第 4 步：输出矛盾清单

每条矛盾必须包含：

- **双侧引证**：章节号 + 原文摘录（矛盾的两边各一份）
- **严重度**：致命（逻辑崩塌，读者必发现）/ 明显（细心读者会发现）/ 轻微（吹毛求疵级）
- **修改建议**：改哪一侧、怎么改，优先改动小的一侧

核对后无矛盾的类别也必须写明"已核对，未发现矛盾"——沉默不等于清白。报告结尾附"伏笔台账"：已回收 / 未回收（截至已读范围）。

## 质量标准

- 每条结论必须有章节依据，禁止"感觉上前后不一致"这类无引证判断
- 长篇抽样分析时，明确标注覆盖范围（"已核对第 1-50 章及每卷卷末，共 XX 章"）
- 允许"打破规则但自洽"：前文违反设定但文中给出了解释（奇遇、特殊体质）的，不算矛盾，但可列入"存疑"请作者确认
- 报告面向作者，只讲矛盾与修改建议，不复述剧情
