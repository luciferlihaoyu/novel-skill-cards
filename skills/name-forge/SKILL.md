# 取名炉

名字是小说的第一笔设定：好名字自带信息量（出身、气质、阵营），坏名字让读者出戏。本技能按"约束 → 生成 → 筛查"三步走，**批量产出，附带寓意**，让作者挑而不是让作者想。

## 工作流程

### 第 1 步：收集约束

用户没给全就按题材推断，仅在关键信息缺失时补问一句：

- **题材体系**：玄幻/仙侠/都市/历史/西幻/科幻（决定命名范式）
- **对象类型**：人名 / 地名 / 功法 / 法宝 / 势力 / 丹药 / 章节名
- **气质**：正派、邪道、隐士、皇族、市井……
- **硬约束**：字数、必须含/避开的字、姓氏指定、与已有名的协调性

### 第 2 步：批量生成

加载 `references/naming-playbook.md`，按对应品类的造词配方生成：

- **数量**：默认 10-15 个候选，分 2-3 个风格档位（如"雅致档 / 霸气档 / 怪趣档"）
- **每个候选附**：寓意（一两句）、音律简注（平仄顺口度）、适配场景
- 人名按姓氏 + 名拆开设计，给出"名与姓咬合度"考虑（声调搭配、避免连读歧义）

### 第 3 步：筛查（必须执行）

对入选候选做四查，不通过的标出原因：

1. **谐音梗**：连读是否产生歧义或不雅联想（"杜子腾"式事故）
2. **重名风险**：是否与顶流网文/名著的著名角色重名（如"萧炎""叶凡"级别的名字直接排除）
3. **用字一致性**：同一世界观内用字风格统一（仙侠用"霄/宸/衍"系就别混进"伟/强/丽"）
4. **发音顺口度**：连续叠声母/韵母（"张庄章"）、绕口感

## 质量标准

- **名字要带货**：每个名字附带一句"这个名字暗示了什么"，没有信息量的名字不出炉
- **服从世界观**：所有候选必须像同一本书里长出来的，风格跳跃的分档隔离
- **反派名字不必都难听**：高级反派名反而雅（"闻人破军"好于"恶霸天"），按用户书的层级给
- 批量配角名可降配（寓意从简），主角团与重要势力必须全配
