# 命名配方手册

## 人名

### 仙侠/玄幻配方
- **姓**：优先复姓与冷僻姓提档次（闻人、司空、东方、澹台、独孤），主角用单姓更亲民（林、苏、叶、沈——注意这些都是高频主角姓，要给差异点）
- **名用字库**：
  - 清冷气：霄、寒、霜、璃、缈、湛、泠
  - 厚重气：宸、衍、衡、岳、钧、稷
  - 锋锐气：斩、朔、烈、戈、铮
  - 女名柔而不弱：绾、蘅、妩、照、翎（避免纯花草堆砌）
- **配方**：气质字 + 动态字（"顾听澜"——静姓配动名有张力）；避免两字同气质（"霸天""无敌"类为低级反派专属）

### 都市配方
贴近真实姓名库但避开爆款名（子轩、梓涵系）；反派可用谐音暗讽但要能过筛查。

### 历史配方
按朝代用字：先秦单名（"政""轲"）、汉名单名为主、唐宋可双名；表字与名意义相关（诸葛亮字孔明——亮与明互训）。

### 西幻配方
音译名控制 2-4 音节，同阵营用统一音系（如精灵多用 l/th 音：Elarion、Thalor），附原文拼写。

## 地名
- **配方 A 景物+地势**：落霞坡、断魂崖、青冥渊
- **配方 B 典故压缩**：望舒台（月御望舒）、息壤城
- **配方 C 功能直给**：坊市、渡口类小地名越朴实越真（"三步桥"好于"凌霄圣桥"）
- 危险地用凶字（绝、断、葬、泣），福地用盈字（蕴、华、灵、秀）

## 功法/招式
- **层级感**：低阶功法名字朴素（《基础剑诀》），高阶用大词（《太上忘情录》），名字即剧透等级
- **配方**：[意象][动作/境界]：九霄雷引、大衍神照、踏雪无痕
- 招式名喊得出口：战斗中喊的招式 ≤ 5 字，音节铿锵（仄声收尾更有力）

## 势力/宗门
- 正派：山、宗、阁、院 + 清/玄/明/正系字（清微宗、悬剑阁）
- 邪道：教、宫、殿 + 幽/血/冥/蚀系字（蚀月教、幽泉宫）——高级反派势力可用雅名反差（"白衣渡"）
- 中立/商业：楼、行、会（万金楼、听雨楼）

## 法宝/丹药
- 法宝：[材质/意象]+[器形]：紫电锤、山河扇、混元珠；成长型法宝名字留升级空间
- 丹药：[功效]+[丹/丸/露/膏]：筑基丹、回春露；毒药用艳名（含笑半步癫式怪趣可入怪趣档）

## 章节名
- 单卷内章节名风格统一：全部四字 / 全部七字 / 全部主谓结构
- 免费平台章节名可当半个钩子（"第 40 章 身份曝光"），付费平台可雅致（"雪夜访旧"）

## 筛查清单

1. 拼音连读三遍，查谐音歧义（shi/zi/ji/ba 音组合重点排查）
2. 搜索比对顶流作品主角名与著名角色名，撞车即弃
3. 同一页角色名单读一遍，避免两个字名同声母扎堆（李凌、林岚同页）
4. 反派名过一遍"雅度测试"：这本书的反派层级配得上这个名字的难听度吗
